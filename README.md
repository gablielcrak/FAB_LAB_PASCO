# Fab Lab Pasco

Sitio estático del Fab Lab Pasco, listo para publicarse en GitHub Pages.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub (por ejemplo `web_fablab_pasco`).
2. Sube todos los archivos de esta carpeta a la rama `main`.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment** elige:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Guarda. En uno o dos minutos el sitio quedará en:

`https://TU-USUARIO.github.io/web_fablab_pasco/`

Si el repositorio se llama `TU-USUARIO.github.io`, el sitio se publica en la raíz:

`https://TU-USUARIO.github.io/`
